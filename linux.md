# Linux 

## базові команди 

1: cd = перейти в директорію 
2: mkdir = зробити директорію 
3: rm/rm-rf = видалити файл або директорію 
4: nano/vim = редактувати файл в терміналі 
5: touch = зробити файл 
6: chmod = змінати права


## Редактори 

1: nano = простіше для старта 
2: vim = треба привикнути/ефективніше 


## Як поглиблюватись? Навігація і робота з файлами 

1: find = шукає файли за назвою,типом,розміром,датою.Шукаю "наживо" тому повільніше,але точно 

2: locate = тоже шукає файли але по готовій базі,тому дуже швидко. Базу оновлюватись командою sudo updatedb

3: Three = показати структуру папок як дерево 

tree    вся структура 
tree -L 2    тільки 2 рівні вглиб 

для того шоб зрозуміти як влаштований проект якшо команди нема треба встановити sudo apt install tree


4: ln = створити посилання на файл 

ln -s /etc/nginx/sites-avaible/site /etc/nginx/sites-enabled/site

-s = створює символьне посилання аналог ярлика віндовс якшо видалити орігинал то посилання зламається 

без -s = створюється жорстке посилання ше одне імя для того самого incode файл живе поки існує хочаб 1 імя

для того шоб не копіювати файл в пару місць а посилатись на 1 класичний приклад = включення сайтів в nginx


stat = повна інформація про файл 

stat file.txt 

Показує розмір,права,номер incode,власника,кількість жорстких посиланнь і дати 

Для того шоб зясувати коли файл змінювали і хто власник 


file = визначити тип файлу 

file photo.jpg
photo.jpg: PNG image data 

Linux визначає тип за вмістом а не за розширенням 

Для того шоб поняти шо це за файл якшо розширення нема або воно бреше 


                 Потоки і перенаправлення 
                3 стандартні потоки 

в кожної програми є 3 канала:
    Потік                 Номер                        Шо це 
    stdin                   0   вхід,звідктипрограма бере данні 


     stdout                 1    простий вивід: результат роботи


     stderr                 2            вивід помилок 


Помилки йдуть окремим каналом шоб їх можна було відділити від результату 
                      

                      Перенаправление 

ls > files.txt                stdout в файл(Перезапускає файл)
ls >> files.txt               stdout в кінець файла (дописує)
ls /nope 2> errors.txt        тільки помилки (потік 2) в файл
command > all.log 2>&1        і вивід і помилки в 1 файл
command 2> /dev/null          викинути помилки ("чорна дира")

2>&1 = "потік 2 (помилки) відправ туда ж куда йде потік 1" Порядок важливий: перше >файл потім 2>&1
Для того шоб зберіграти логи скриптів приховувати непотрібні помилки 


Пайп | = передає вивід 1 команди на вхід іншої  так з малих команд збирається мощьний інструмент 

cat app.log | grep ERROR | wc =l  скільки рядків з ERROR в лозі 
ps aux | grep nginx          чи запущений nginx

Тому шо без пайпів неможна писати однорядники тобто вирішувати задачу одним рядком в терміналі
